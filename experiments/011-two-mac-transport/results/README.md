# Experiment 011 Results

Transport result folders:

- `wifi-6e/`: two-Mac run over Wi-Fi 6E.
- `wired-ethernet/`: two-Mac run over wired Ethernet.
- `thunderbolt/`: reserved for the Thunderbolt networking run.
- `loopback-receiver/` and `loopback-sender/`: local smoke test artifacts.

Each network transport folder contains its own `sender/`, `receiver/`, and
summary report files.
